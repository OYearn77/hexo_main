## 威力外推介绍

在环境噪声不变的前提条件下，目标距离越远所反射的雷达回波幅度越小，在距离-幅度图上表现为目标距离越远目标所对应的峰值越小。CFAR检测时使用**固定的检测门限**，可能出现无法检测到目标的情况，双基地相参合成使得信噪比提升3dB和6dB，这些提升值使得在某些距离下通过相参合成使得可以成功发现目标。

具体外推值为：单基地检测极限点--MISO相参合成检测极限点；MISO相参合成检测极限点--MIMO相参合成检测极限点。由于影响因素过多如：工作频率、发站到目标、目标到收站的电磁波传播衰减、发站和收站的天线高度等系统和环境因素等，无法计算仿真真实情况，同时在不同环境下实测值也会变化，这里简化这些影响因素，选定一个**标准距离值**，设定一个**衰减系数**根据距离进行衰减，进行仿真和威力外推演示。

注：此方案两雷达距离不能过远，两雷达距离过远时的威力外推即为**双基地威力外推**。双基地威力外推符合Cassini卵形线，这里不多做介绍。![图片1.png](https://s2.loli.net/2025/07/12/eNXPuTWpg7AkynR.png)

## 单点威力外推MATLAB仿真

控制归一化回波幅度大小 + 距离目标所反射能量衰减

```ap
 standard_R=5000;%控制归一化回波幅度大小
    att=0.0078;
    % 模拟原始目标回波
    temp_1t1r=zeros(zizhen_size,nTr); %一个周期最多采nTr个点；
    for count=1:zizhen_size
        temp_1t1r(count,:) =att*(standard_R/R1)^4.* gate_1t1r(count,:).*(cos(2*pi*f1*t0+pi*u*(t0 - delay_1t1r(count)).^2-2*pi*F1*delay_1t1r_F(count)+2*pi/lamda*(zizhen_location(count,:)*uw)));%雷达1发雷达1收
    end
    temp_2t2r=zeros(zizhen_size,nTr); %一个周期最多采nTr个点；
    for count=1:zizhen_size
        temp_2t2r(count,:) =att*(standard_R/R2)^4.* gate_2t2r(count,:).*(cos(2*pi*f2*t0+pi*u*(t0 - delay_2t2r(count)).^2-2*pi*F2*delay_2t2r_F(count)+2*pi/lamda*(zizhen_location(count,:)*uw)));%雷达2发雷达2收
    end
    temp_1t2r=zeros(zizhen_size,nTr); %一个周期最多采nTr个点；
    for count=1:zizhen_size
        temp_1t2r(count,:) =att*(standard_R/(R1+R2)*2)^4.* gate_1t2r(count,:).*(cos(2*pi*f1*t0+pi*u*(t0 - delay_1t2r(count)).^2-2*pi*F1*delay_1t2r_F(count)+2*pi/lamda*(zizhen_location(count,:)*uw)));%雷达1发雷达2收
    end
    temp_2t1r=zeros(zizhen_size,nTr); %一个周期最多采nTr个点；
    for count=1:zizhen_size
        temp_2t1r(count,:) =att*(standard_R/(R1+R2)*2)^4.* gate_2t1r(count,:).*(cos(2*pi*f2*t0+pi*u*(t0 - delay_2t1r(count)).^2-2*pi*F2*delay_2t1r_F(count)+2*pi/lamda*(zizhen_location(count,:)*uw)));%雷达2发雷达1收
    end
```

## 单点威力外推上位机生成DSP判断

修改上位机生成回波规则

```apache
const double dReferenceRange = 1000.0; // 参考距离1000m
double dAverageRange = (R1 + R2) / 2.0; // 平均距离
dRangeAttenuationFactor = pow(dReferenceRange / dAverageRange, 3); // 距离衰减因子 (参考距离/实际距离)^2
//// 限制衰减因子范围，避免过度衰减或放大
//if (dRangeAttenuationFactor > 10.0) dRangeAttenuationFactor = 10.0;
//if (dRangeAttenuationFactor < 0.01) dRangeAttenuationFactor = 0.01;
```
