## 点击“加载回波”按钮回调

`DataLoadOpDlg.cpp`文件，入口函数：`void CDataLoadOpDlg::OnBnClickedButtonLoadStart()`点击“加载回波”按钮时，会调用这个函数，进行参数的下发。

下发参数的内存结构：`LOAD\_PARAM\_CFG\_CMD\_T`结构体的内存布局，上位机通过串口下发参数给FPGA。

```c
typedef struct _FRAME_HEAD_T
{
    WORD wHeadId1;      // 包头1
    WORD wHeadId2;      // 包头2
    WORD wHeadId3;      // 包头3
    DWORD dwFrameType;  // 帧类型
    DWORD dwRsv;        // 保留/扩展
    DWORD dwFrameLen;   // 帧长度
} FRAME_HEAD_T;

typedef struct _FRAME_END_T
{
    WORD wEndId1;       // 包尾1
    WORD wEndId2;       // 包尾2
} FRAME_END_T;

typedef struct _LOAD_PARAM_CFG_CMD_T
{
    FRAME_HEAD_T stHead;    // 帧头
    BYTE btChNum;           // 通道数
    BYTE btWorkMode;        // 工作模式
    WORD wADr_ChSel;        // AD通道选择
    WORD wDAr_ChSel;        // DA通道选择
    DWORD dwSita;           // 角度参数
    DWORD dwADf1Check1;     // AD校验1
    DWORD dwADf2Check1;     // AD校验2
    // ...（中间还有很多DWORD/WORD/BYTE类型的参数，见你的赋值代码）...
    WORD wLLRPrtWidth;
    WORD wLLRPrtNum;
    WORD wLLRCpiNum;
    // ...（更多PRT、CPI、门限等参数）...
    WORD wWaveGate1;
    WORD wWaveGate2;
    // ...（一直到wWaveGate20）...
    BYTE btWinNum;          // 窗口数
    BYTE btCrcCheck;        // CRC校验
    FRAME_END_T stEnd;      // 帧尾
} LOAD_PARAM_CFG_CMD_T; 

```

结构体定义在`mwRadarCtrlComm.h`中 名为`stParamCfgReq`，发送时将`stParamCfgReq`的内容使用“内存拷贝”实现，赋值完成后为适配下位机的字节序（大小端），对每个字段做了字节序翻转，赋值到stParamCfgReq1。

```c
stParamCfgReq1.stHead.wHeadId1 = publicFun::data_flipr(stParamCfgReq.stHead.wHeadId1);
```

## 两台根据导引进行回传与波门修正

由于每台导引头只能接收本台的导引信息即本台与目标的距离、方位角和俯仰角，如果不进行，本台处理另一台的回波前沿估计、波门前沿计算与距离测量将会一直处于不可修正状态。

现在将两台dsp1的测量结果传给各台的dsp2，传输结构如下![DSP回传newww.png](https://s2.loli.net/2025/07/07/n2egkVK9uAzhcEY.png)!

dsp1内存传输如下![Snipaste_2025-07-06_15-45-12.png](https://s2.loli.net/2025/07/07/VATpH4kXyBIGw1b.png)

dsp2接收参数如下![mimo新接收参数.png](https://s2.loli.net/2025/07/07/yImhQ53HG6CFaKr.png)

以上为单基地接收数据，双基地数据结构一样紧邻排布。dsp2提取两经过引导信息修正的测距值，填充到dsp1回传上位机的距离值中，与此同时FPGA提取第五个值（回波前沿点2），这个值是经过引导信息纠正后的另一台的回波前沿，将这个数覆盖到下个cpi发送给dsp1参数的`0x81D00024`处对下个cpi双基地的测量进行修正。

即流程如下，FPGA处理第3个CPI时，DSP根据引导信息修正本台第2个CPI的测量值，同时修正另一台第二个cpi测量值，回传给FPGA修正第4个CPI的参数与处理。（注：`0x81D00024`点只有第二个cpi开始才会进行双基地修正值的覆盖）
